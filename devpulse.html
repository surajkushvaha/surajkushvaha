Hacker News and GitHub are called directly (both send proper CORS headers). Reddit and GamerPower don't send CORS headers to browsers at all, so those two are routed through a public CORS relay (allorigins.win, falling back to corsproxy.io) which just re-serves the same public JSON with the right header added — no login, no key, no private data involved. If a panel still errors, the relay is likely rate-limited or down; use the source link in the error message to check it directly.
